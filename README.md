# Фильтр курсов СДО (Moodle)

Лёгкое расширение для Firefox и браузеров на базе Chromium (Chrome, Edge, Яндекс Браузер), которое скрывает лишние и архивные дисциплины на странице **«Мои курсы»** СДО Московского Политеха (`https://online.mospolytech.ru/my/courses.php`) и в боковом блоке «Мои курсы» (`block_course_list`).

## Возможности

- **Скрытие галочкой в 1 клик**: напротив каждой строки в таблице «Я изучаю» (`block_mylearninghistory`) появляется переключатель `Скрыть`.
  - Курс сохраняется по его **уникальному ID** (из `course/view.php?id=...`), поэтому курсы с одинаковым названием не перепутаются.
  - После скрытия на 5 секунд появляется уведомление с кнопкой **«Отменить»**.
- **Скрытие по названию (правила)**: в панели прямо над таблицей или в popup-окне расширения можно вести список слов/фраз (по одной на строке):
  - обычная строка ищет подстроку без учёта регистра (например, `Анкетирование`);
  - строка, начинающаяся с `=`, требует точного совпадения названия без учёта регистра (например, `=Элементы математического анализа`).
- **Встроенная панель управления над таблицей**:
  - быстрый поиск по видимым курсам;
  - кнопка **«Показать скрытые (N)»** для временного просмотра скрытых строк и быстрого снятия/установки галочек;
  - кнопка **«Список и правила»** — раскрывает редактор правил и список скрытых курсов прямо на странице СДО;
  - кнопка **«Фильтр: Вкл / Выкл»** — временно отключает фильтрацию без удаления списков.
- **Синхронизация и бэкап без правки кода**:
  - настройки сохраняются в `chrome.storage.sync` (с резервным копированием в `chrome.storage.local`) и применяются мгновенно во всех открытых вкладках;
  - поддерживается экспорт/импорт настроек в JSON (через встроенную панель или popup).

## Установка в Firefox

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение…** и выберите `manifest.json` из папки проекта.
3. В `about:addons` → расширение → «Разрешения и данные» включите доступ к `online.mospolytech.ru` (в Firefox с Manifest V3 он не выдаётся автоматически) и обновите страницу СДО.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки расширение нужно подписать на addons.mozilla.org.

## Установка в Chrome / Edge / Яндекс Браузер

1. Скачайте или клонируйте репозиторий.
2. Откройте страницу расширений в браузере: `chrome://extensions` (или `edge://extensions` / `browser://extensions`).
3. Включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку [`moodle-course-hider`](moodle-course-hider).
5. Откройте `https://online.mospolytech.ru/my/courses.php`.

## Структура проекта

- [`moodle-course-hider/manifest.json`](moodle-course-hider/manifest.json) — манифест Manifest V3 (разрешение только `storage`, запуск на `https://online.mospolytech.ru/*`).
- [`moodle-course-hider/shared.js`](moodle-course-hider/shared.js) — модель состояния, сопоставление по ID и правилам названия, работа с `chrome.storage` и экспорт/импорт JSON.
- [`moodle-course-hider/content.js`](moodle-course-hider/content.js) и [`moodle-course-hider/content.css`](moodle-course-hider/content.css) — фильтрация курсов в DOM, предотвращение мигания при загрузке, панель управления и галочки в строках.
- [`moodle-course-hider/popup.html`](moodle-course-hider/popup.html), [`moodle-course-hider/popup.css`](moodle-course-hider/popup.css), [`moodle-course-hider/popup.js`](moodle-course-hider/popup.js) — popup-меню расширения с вкладками «Курсы», «По названию» и «Бэкап».
- `moodle-course-hider/icons/` — иконки расширения (`16×16`, `48×48`, `128×128`).
